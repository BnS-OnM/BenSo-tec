PDF Quote Import

Import quotes from PDF files into Odoo

Features

Easy PDF Upload

Simple wizard interface for uploading and processing PDF quote files.

Automatic Import

Automatically extract text and create sale orders from PDF files.

How It Works

  1. Navigate to Sales > PDF Quote Import > Import PDF Quote
  2. Upload your PDF file
  3. Select a customer (optional)
  4. Click Import to process the PDF
  5. Review the created sale order

Requirements

This module requires the PyPDF2 Python library:

pip install PyPDF2
